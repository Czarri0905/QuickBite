# QuickBite
QuickBite is a self-service restaurant ordering kiosk application designed to make ordering fast, simple, and convenient. Customers can easily browse the menu, customize their meals with add-ons, review their order with automatic total calculation, and complete their payment smoothly.

Developed by: Prince Eco F. Barlisan, Alexis John C. Parba, and Cedji B. Teoxon
